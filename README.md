# RML Hospital Super Speciality Block — Network Design

## 📌 About the Project

This project is a network design and simulation of the Super Speciality Block of **Dr. Ram Manohar Lohia Institute of Medical Sciences (RMLIMS), Lucknow**, created using Cisco Packet Tracer.

The idea for this project came from my personal visits to the hospital while my uncle was admitted there. That experience inspired me to explore how network infrastructure can support communication and connectivity within a hospital environment.

The project represents my attempt to model the building's network system in Cisco Packet Tracer and apply networking concepts to a real-world healthcare setting.

## 🎯 Project Objectives

- Understand how network infrastructure can be organized within a hospital building.
- Design and simulate network connectivity using Cisco Packet Tracer.
- Gain practical experience with networking devices and network topology.
- Apply theoretical networking concepts to a real-world-inspired environment.
- Improve my understanding of network design and troubleshooting.

## 🛠️ Tools Used

- **Cisco Packet Tracer** — Network design and simulation
- **Networking Concepts** — Network topology, device connectivity, and configuration

## 🏥 Real-World Inspiration

Unlike a purely hypothetical networking exercise, this project was inspired by a place I personally visited. Observing the hospital environment motivated me to explore the networking infrastructure behind a large healthcare facility.

The simulation is intended to represent the network system as I understood it and modelled it. It should not be considered an officially verified or exact reproduction of the hospital's production network.

## 🚀 Learning Outcomes

Through this project, I aim to strengthen my practical understanding of:

- Network topology design
- Network device configuration
- Connectivity between network devices
- Network simulation using Cisco Packet Tracer
- Applying networking fundamentals to real-world scenarios

## 📂 Project File

- `RML Hospital Project.pkt` — Cisco Packet Tracer project file.

## ▶️ How to Open the Project

1. Install Cisco Packet Tracer.
2. Clone or download this repository.
3. Open `RML Hospital Project.pkt` in Cisco Packet Tracer.
4. Explore the network topology and inspect the device configurations.
